Gerar chaves de aviso (push)

Esta página roda só no seu computador. Nada é enviado para a internet. Clique, copie cada valor direto para o Netlify e feche a página.

1) NEXT_PUBLIC_VAPID_PUBLIC_KEY (pública, pode aparecer no site)
2) VAPID_PRIVATE_KEY (SECRETA: só no Netlify, marcada como secreta; nunca no chat nem no GitHub)
3) CRON_SECRET (SECRETA: senha do agendador; use o mesmo valor no GitHub Actions)
4) VAPID_SUBJECT (escreva você: mailto: + seu e-mail. Ex.: mailto:contato@seudominio.com)
